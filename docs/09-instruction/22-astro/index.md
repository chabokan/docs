# سرویس Astro

`Astro` فریمورکی برای ساخت وب‌سایت‌های استاتیک و پرسرعت است که با پشتیبانی از فریمورک‌های مختلف مانند React، Vue، و
Svelte، امکان ساخت سایت‌های مقیاس‌پذیر و بهینه را فراهم می‌کند. این فریمورک به‌طور پیش‌فرض تنها HTML و CSS را بارگذاری
کرده و JavaScript را فقط در صورت نیاز فعال می‌کند، که باعث کاهش زمان بارگذاری و مصرف منابع می‌شود.

`Astro` گزینه‌ای عالی برای سایت‌های استاتیک با نیاز به عملکرد بالا است.
